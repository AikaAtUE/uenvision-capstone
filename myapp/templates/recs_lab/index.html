A second recommendation system that runs next to the current one without changing it. It adds two things the current one is missing: skill categories (what kind of skill it is, and which skills can stand in for each other) and subject blueprints (what each subject is for). Job postings and survey answers then rank what is left. Every number is a count from the extracted skills and hard skills data sets.
