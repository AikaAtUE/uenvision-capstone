Purpose of this survey: to measure how easy UEnvision is to use. The System Usability Scale is a standard 10-question test that gives UEnvision a usability score from 0 to 100.

Functional test case sheet

Purpose of this survey: to confirm that every feature of UEnvision works as it should. Your results show the team which parts work and which need fixing.

A functional test checks that each part of UEnvision does what it is supposed to do. For each test case, do what the scenario says, then answer whether it happened as expected. If it didn't, write what happened instead. Comments or remarks about your experience are welcome on any test case.
