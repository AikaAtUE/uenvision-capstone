Purpose of this survey: to find out which technical skills each BSIT and BSCS subject teaches, and how far (Introduced, Practiced or Applied). UEnvision compares this with the skills IT and Computer Science job postings ask for, to show which in-demand skills the curriculum already covers, which are under-taught, and which subjects could add them.

How to answer

  1. Read the Data Privacy Notice and tick the box to agree.
  2. Tick every subject you teach this semester and last semester (Select all ticks a whole list). Use + Add a subject that isn’t listed for one that is missing, like an elective.
  3. For each subject, type or pick the technical skills you cover and choose how far each one is taught: Introduced, Practiced or Applied. Each level is explained above the skill boxes. Press × on a subject's box to remove it.
  4. Press Submit survey. If you have answered before, your saved answers are shown first: press Edit, change them, then press Save changes. Clear all answers unticks every subject and removes every skill on the page (nothing is saved until you submit).
